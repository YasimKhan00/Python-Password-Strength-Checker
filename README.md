# 🔐 Python Password Strength Checker

## 📌 Project Overview

The **Python Password Strength Checker** is a beginner-friendly cybersecurity project developed using Python. It evaluates password strength through basic validation techniques and provides feedback to help users create stronger passwords.

The project demonstrates fundamental Python programming concepts while promoting password security awareness.

## ✨ Key Features

- Password length validation (minimum 12 characters).
- Uppercase letter detection.
- Lowercase letter detection.
- Number detection.
- Special character detection.
- Password strength classification (Weak, Medium, Strong).
- Security score out of 5.
- Helpful suggestions for improving password strength.
- Hidden password input using Python's `getpass` module.
- Empty password validation.

## 🛠️ Technologies Used

- Python 3
- String Module
- Getpass Module

## ⚙️ How to Run the Project

### Step 1: Install Python

Download and install Python 3 from:

https://www.python.org/downloads/

### Step 2: Download the Project

Clone the repository:

```bash
git clone https://github.com/YasimKhan00/Python-Password-Strength-Checker.git
```

Or download the project as a ZIP file.

### Step 3: Open the Project Folder

```bash
cd Python-Password-Strength-Checker
```

### Step 4: Run the Program

```bash
python password_checker.py
```
